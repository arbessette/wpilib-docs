# Coding Basics: Before You Start

Same concepts whether you're headed for FRC or FTC. If you've written code
before, skip ahead to :doc:`introduction`.

.. rubric:: Core Concepts
   :class: wl-shared-text

.. grid:: 1 2 2 4
   :gutter: 3

   .. grid-item-card:: Variables

      Store a value, like a motor speed or a sensor reading, under a name
      so your code can use it and change it later.

   .. grid-item-card:: Functions

      Group a sequence of instructions into a single, reusable action, such
      as "drive forward" or "raise the arm."

   .. grid-item-card:: Classes and Objects

      The structure you'll see in every robot project: a ``Robot`` class,
      subsystem classes, and the objects created from them.

   .. grid-item-card:: Reading Code

      Learn to follow an example line by line and predict what it does
      before you start changing it.

.. tip::

   **Want a full course first?** Try
   `Codecademy Java <https://www.codecademy.com/learn/learn-java>`_ or the
   `Python learning guides <http://docs.python-guide.org/en/latest/intro/learning/>`_.
   You don't have to finish one before continuing: you can wire your robot
   (Step 1) or configure your control system (Step 3) while you learn to
   code in parallel.
